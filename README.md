# CoffeeShop

A static, interactive café showcase for Little Ember Coffee. It introduces the café, its current coffees, and visitor information; it does not include online ordering.

## Website files

- `artifacts/coffee-shop/index.html` — page content and metadata
- `artifacts/coffee-shop/styles.css` — responsive styling
- `artifacts/coffee-shop/script.js` — coffee filters, mobile navigation, copy-address button, and scroll reveals
- `artifacts/coffee-shop/little-ember-interior.png` and `artifacts/coffee-shop/coffee-stilllife.png` — page photography

The site is built with plain HTML, CSS, and JavaScript and served through Vite for local preview.
